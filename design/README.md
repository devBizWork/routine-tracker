# Design reference

The 16 core screens from the "Routine Tracker — App screens" canvas, one HTML file each.
Open any file in a browser to see it; links between screens work. They are static mockups:
sample data is fixed, and no buttons do anything yet.

| File | Screen |
| --- | --- |
| Main.html | Today (home) |
| Calendar.html | Calendar |
| Day.html | Day timeline (past day) |
| Tasks.html | Tasks |
| AddTask.html | Add / edit task (sheet) |
| LogTime.html | Log time (sheet) |
| DayReview.html | Day review |
| Trends.html | Trends |
| Settings.html | Settings |
| FirstRun.html | First run (empty day) |
| Install.html | Add to Home Screen |
| WelcomeBack.html | Reopened: catch-up + tap to enable sounds |
| TodayMuted.html | Sounds muted + backup reminder |
| ReviewFlow.html | Review today (log later) |
| Restore.html | Restore backup: Merge or Replace |
| States.html | Block states & signals |

## Theme

theme-option-z.html is Option Z, Summer at the Pool: the colors, task categories and body
font the app uses. The screens were drawn in an older purple palette; CLAUDE.md maps each
old color to its Option Z replacement. No other theme option is used.
